## Bukti bahwa test benar-benar menjaga perilaku

Setiap test ditulis merah dulu terhadap kode lama, kecuali `006-relative-import-check` (ditulis bersamaan dengan versi baru `check.ts`, lalu dibuktikan lewat mutasi). Setelah itu **23 mutasi** sengaja ditanam satu per satu di kode, dan suite terkait harus gagal:

- **21 tertangkap** setelah perbaikan; 2 sisanya menunjuk dead code yang lalu dihapus.
- Putaran kedua (setelah `/bfb-review` audit log): **10 mutasi** baru ditanam dan 10/10 tertangkap.
- Putaran kelima (2026-10-05, setelah `/bfb-ship`): test baru untuk probe caption (baris baru, spasi ganda, emoji), `askYesNo`, `checkSetup`, `loadRows`, dan selektor yang dibatasi ditulis merah dulu. Dua mutasi di selektor tertangkap: `contains(text(), "Posting")` ditambahkan kembali ke `publishPost`, dan cabang "Oke" dilepas dari panel "Pembaruan Reels".
- Putaran keempat (2026-10-05): test baru `parseArgs`, `selectRows`, CLI entry, help, `humanClick` (scroll), `humanType` (`interrupt`), dan selektor baru ditulis merah dulu lalu hijau. Dua mutasi di `parseArgs` (dedupe NO dihapus; `-e` tanpa `-b` dianggap menu) masing-masing tertangkap oleh test yang tepat.
- Putaran ketiga (fitur bilingual & emulasi manusia): selektor diuji terhadap teks dwibahasa, helper delay diuji rentang dan error batasnya, pengetikan diuji urutan per karakter beserta jeda, mouse click diuji bounding box random point dan fallback-nya, serta runner diuji jeda antar barisnya.

## Coverage (`bun run test:coverage`)

Hanya file yang di-import oleh proses test yang dihitung: **100% fungsi, 100% baris** untuk 34 dari 45 file di `src/`. File yang dijalankan lewat proses terpisah (`src/index.ts`, `src/commands/bypass.ts`, `src/commands/help.ts` di `integration/007-cli-entry`) dan file yang tidak di-import test sama sekali (tabel di bawah) tidak muncul di laporan; Bun 1.4.2 tidak punya opsi untuk memasukkannya. `bunfig.toml` mewajibkan **per file** **100% baris dan fungsi** (`coverageThreshold = 1.0`), dan CI menjalankan `bun run test:coverage`.

Seluruh helper di `src/libs/` yang disentuh (`parse-args.ts`, `select-rows.ts`, `load-rows.ts`, `check-setup.ts`, `ask-yes-no.ts`, `human-type.ts`, `human-click.ts`, `facebook-selectors.ts`, `random-delay.ts`, `run-browser-rows.ts`) mencapai **100.00% baris dan fungsi**.
